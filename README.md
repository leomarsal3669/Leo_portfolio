## 🎨 Key Features & Architectural Highlights

1. **Modern Dark Theme & Glassmorphism UI**:
   - Custom CSS custom properties with dark slate base (`#0F172A`, `#1E293B`) and vibrant gradient accents (`#3B82F6`, `#06B6D4`, `#10B981`, `#7C3AED`).
   - Glassmorphic cards with backdrop blur filters, glowing borders, and 3D card tilt physics.
   - Dynamic theme switcher (`Dark Mode` / `Light Mode`) with persistence in `localStorage`.

2. **Interactive AI Demo Sandbox**:
   - **AI Resume Skill Analyzer**: Live NLP keyword parsing simulator comparing candidate resume content against target job profiles (Data Analyst, AI Engineer, Full Stack Dev). Generates TF-IDF similarity metrics and gap reports.
   - **Deepfake Forensic Inspector**: Interactive neural network inspector simulating multi-channel audio spectrogram analysis (Librosa) and video frame tensor tracking (OpenCV).

3. **Full Interactive Portfolio Modules**:
   - **Preloader**: Futuristic progress counter and smooth splash sequence.
   - **Global Command Search (`Ctrl + K` / `Cmd + K`)**: Instant search overlay filtering skills, projects, certifications, and experience.
   - **Hero Section**: Dynamic typing effect, profile photo card with tilt, animated stats counter strip (7.72 CGPA, 3 Internships, 3 Core AI Projects, 7 Certifications).
   - **Skills Matrix**: Interactive domain filtering pills (Programming, AI/ML, Analytics, Frontend & IoT) and instant search.
   - **Internship Timeline**: Detailed breakdown of industry experience at Judah Code Technologies, e-Soft IT Solutions, and Akilam Technology.
   - **Featured Projects**: Multimodal Deepfake Detection, AI Resume Analyzer, and Human Following Smart Vehicle with interactive detail modals and code snippets.
   - **Academic Record**: B.Tech AI & Data Science details (CGPA 7.72), HSC, and SSLC.
   - **Certifications & Achievements**: Interactive cards for 7 industry certifications and competition milestones (PROJECT PRISM, SHARK TANK '26).
   - **Embedded Resume Viewer**: Formatted curriculum vitae preview with Copy Summary, Print, and Direct Download options.
   - **Interactive Contact Form**: Client-side validation, direct email actions, and toast notifications.

## 🛠️ Local Development & Deployment

### Run Locally with Vite or Static Server
```bash
# Clone repository
git clone https://github.com/leomarsal3669/leomarsal3669.github.io.git

# Navigate into project directory
cd leomarsal3669.github.io

# Start development server
npm run dev
```

### Deploy to GitHub Pages
1. Push all files to your GitHub repository `https://github.com/leomarsal3669/leomarsal3669.github.io`.
2. Go to **Settings** > **Pages** in your repository.
3. Select `main` (or `master`) branch as the source and click **Save**.
4. Your portfolio will be live at `https://leomarsal3669.github.io/`!
